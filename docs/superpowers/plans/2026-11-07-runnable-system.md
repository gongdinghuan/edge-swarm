# 蜂群可运行系统补全计划

**目标：** 从空目录配置可持续运行的控制中心，注册实际设备，执行交互和离线任务，处理节点离线与重启，并能通过管理界面查看和控制运行状态。

**范围基线：** [原工程方案](../specs/2026-11-07-edge-swarm-design.md) 的公网独立副本路线。以 SQL 为持久任务权威，不引入未经验证的消息服务；单控制实例配置是本次交付的部署单元。不能把 DeepInfer 原生硬件、跨地域 HA、不同后端间 KV 迁移等未实测方向当作可用功能。

| 工作线 | 可交付物 | 验收 |
|---|---|---|
| 持久任务和节点 | 租约、fence、退避、重连、防重复占用、排空及恢复 | SQLite 回归；可获取真实 PostgreSQL 时跑数据库和网络集成测试 |
| 控制台与调度 | 管理 API、节点能力和状态、租户任务列表、操作界面、会话前缀亲和与健康过滤 | API 越权、排空、任务恢复与路由行为测试 |
| 执行与模型 | 后端探测、节点遥测、可用推理协议；原生 DeepInfer 依官方离线 API 适配 | 真实消费卡模型推理优先；无适配硬件时明确 DeepInfer 实机未验收 |
| 部署与运维 | Windows 常驻启动和停止、Linux worker 服务、PostgreSQL/TLS 部署和安全凭据配置 | 多进程启动/停止、持久重启，配置语法检查与可用平台上的实际测试 |

先写行为测试，再实现最小闭环。最终重跑全套测试、竞态检查、静态检查和多进程演示。若有真实模型端点，记录推理输出、GPU offload 证据和可复现命令。仍依赖用户公网域名、远端机器或未具备硬件的验收项单列。
